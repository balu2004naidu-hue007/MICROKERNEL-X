# MICROKERNEL-X Development Roadmap

MICROKERNEL-X is being developed incrementally as an
exploration of microkernel and embedded operating-system
concepts.

- [x] Define task states
- [x] Design Task Control Block
- [x] Implement basic task representation
- [x] Implement initial task management

- [ ] Implement task selection

- [ ] Synchronization

- [ ] Interrupt handling

## Phase 4 — Testing

- [ ] Unit testing
- [ ] Scheduler testing
